ABOUT

Built to hold up.
Designed to be yours.

The trade nobody should have to make

Most platforms hand you one or the other — infrastructure that survives a busy day, or code you can genuinely shape. I was not willing to trade one for the other, so I build things that do both.

I'm a developer from Bangladesh — Dhaka, with roots in Pabna and Dinajpur. I like building things that feel like magic but run on a plain local network: no cloud, no accounts, no latency to spare.

Most of my work is low-level and close to the metal — UDP sockets, virtual input devices, sensor streams — wrapped in clean UI. If a phone can become a gamepad or a desktop can act on its own, I'm interested.

What I hold to

Your network is your network

All my work is local-first. No telemetry, no accounts, no cloud dependency. Your data stays on your machines.

Control should not require a degree

The moment a tool makes you choose between a locked interface and a code editor, it has failed. Real control belongs in the hands of the person using it.

Say the number

Latency, capacity and limits are published up front. If something is not ready yet, I say so instead of implying it ships today.

Drop in on the server

All my work is public. Follow the repo, open an issue, or just say hello.
