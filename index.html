SYS / ABOUT

Who’s behind the controller

I’m a developer from Bangladesh — Dhaka, with roots in Pabna and Dinajpur. I like building things that feel like magic but run on a plain local network: no cloud, no accounts, no latency to spare.

Most of my work is low-level and close to the metal — UDP sockets, virtual input devices, sensor streams — wrapped in clean UI. If a phone can become a gamepad or a desktop can act on its own, I’m interested.

  • Local-first multiplayer
  • Virtual input devices
  • AI desktop automation
  • UDP / realtime networking
  • .NET 8 / C#
  • Kotlin / Compose
  • Win32 / ViGEm / SendInput
  • Windows Server / Android
